# ChargeCall

Talking battery alerts for Android, without ads: rules like "when the battery drops to 20%, say …" or "remind me every 5 minutes to unplug at 80%", spoken by the device's text-to-speech voice, your own recording, an audio file or a ringtone. Battery health (with optional Shizuku for Android's learned capacity), history charts, a home-screen widget, Quick Settings tiles, profiles and quiet hours. No ads and no tracking; everything stays on the device. The internet is only used to check for and download app updates from this repository.

- Website and setup guide: https://overnightcoder219.github.io/chargecall-app/
- Download: [Releases](../../releases/latest). Each release has the APK and its SHA-256.
